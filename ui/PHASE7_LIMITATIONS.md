# Phase 7 Step 1 - AI Chat Limitations

- NOT real LLM - Rule-based replies only - keyword matching, NO LLM generation
- NO OpenAI / API key / internet call
- Score = rule-based AIEvaluation, NOT human eval
- Context = in-memory, resets on server restart

- Smart Search = Keyword overlap only, NOT vector search, NOT ML / embeddings
- Search index = Real FeatureRegistry + Marketplace items (seeded)

- Recommendations = Rule-based only, NOT ML, NOT AI prediction
- Based on real Analytics counts + Monetization plan/coins

- Quiz = Fixed 5 questions, in-memory score, NOT real exam, NOT leaderboard
- Quiz answers stored server-side, NOT in dashboard JS
